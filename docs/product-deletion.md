# 商品删除与提示

后台商品表仅在“草稿”和“已下架”列表的操作列提供“删除”；“前台展示”和“全部记录”不显示删除入口。点击后先显示商品名称及二次确认弹窗；取消不发送删除请求，只有点击“确认删除”才执行。确认删除会从前台和后台各状态列表移除该商品，并刷新数量。

删除采用 product.deleted_at 标记，同时将状态设为 ARCHIVED。商品、规格和历史订单所需的数据保留；衣囊中的对应项及搭配关系会移除。历史订单、评论、咨询记录和史料仍保留。操作写入 admin_audit 的 PRODUCT_DELETE 记录，已删除商品不会因重启重新上架，也不能通过旧编辑页面恢复。

接口为 DELETE /api/admin/products/{id}?revision={revision}，沿用管理员会话和 CSRF 校验。后端在事务锁内校验商品状态，只允许删除 DRAFT / ARCHIVED；已上架商品即使版本正确也返回 409，需先下架。版本不一致返回 409，重复删除已删除记录可安全重试。旧数据库启动时只新增可空的 deleted_at 字段，不重建表或删除现有数据。

评论在用户提交或修改后立即公开，游客和其他用户都可查看，不再经过审核。旧评论也不再按原审核状态过滤。后台“评论回复”页只保留商家回复输入框和“确认回复”按钮；空白回复不可提交，保存回复不会改变评论的公开状态。历史审核字段仅保留在数据库中用于兼容旧数据，不再通过接口返回或用于可见性判断。前台评论评分为可点击的五颗星，支持悬停预览和键盘选择，仍提交 1–5 的数值。

加入衣囊后只显示一条提示：停留 2.2 秒，再以 0.8 秒透明度渐变消失。再次添加会更新内容并重新计时，也支持手动关闭。启用减少动态效果时不播放过渡动画。后台保存商品不再出现“商品已上架，前台对应朝代目录刷新后即可查看”的横幅。
